# Устройство поиска

## Как отменяется запрос

- [createCountrySearchHandler](src/searchController.ts) вызывает `AbortController.abort()` при каждом изменении ввода, до ожидания нового запроса. Очистка поля тоже отменяет запрос и убирает результаты.
- `AbortSignal.any` объединяет отмену ввода и таймаут в 10 секунд. Этот сигнал передаётся в [searchCountries](src/searchCountries.ts), а оттуда — в `fetch`.
- Отмена своего запроса (`AbortError`) не показывается как ошибка. Таймаут (`TimeoutError`), HTTP-ошибка и обрыв сети показывают ошибку с возможностью повторить поиск. Ответ 404 означает пустой результат.
- Просто игнорировать старый ответ недостаточно: запрос продолжал бы выполняться. Здесь он действительно отменяется. Дополнительная проверка сигнала после ответа не даёт показать данные уже отменённого запроса.

## Зачем нужна задержка

[debounce](src/debounce.ts) ждёт 300 мс после последнего ввода. Каждый новый вызов сбрасывает таймер. Это позволяет допечатать несколько букв, не отправляя запрос на каждую из них.

Без задержки запросов будет больше. При слишком большой задержке поиск будет казаться медленным. Отмена предыдущего запроса происходит сразу, а не спустя эти 300 мс.

## Как готовятся данные и какова сложность

[mapCountryResponse](src/mapCountryResponse.ts) берёт нужные поля ответа, собирает имена языков и валют в массивы. Описание составляется из названия страны, подрегиона или региона и столицы; если население указано, оно добавляется отдельным предложением, включая значение 0. Это простой шаблон из полученных фактов, а не отдельное поле описания в API.

**Big O** показывает, как растёт объём работы при увеличении входных данных. Для одной страны:

- `L` — количество языков, `C` — количество валют, `S` — длина описания.
- Время и дополнительная память — **O(1 + L + C + S)**: функция один раз проходит по языкам и валютам и создаёт описание. Здесь считаем, что создание строки требует работы и памяти пропорционально её длине.
- Остальные поля читаются без перебора. Массив границ не копируется: функция сохраняет ссылку на исходный массив. Поэтому количество границ не увеличивает работу этой функции.

## Принципы чистого кода

- У функций отдельные задачи: [searchCountries](src/searchCountries.ts) делает запрос и проверяет HTTP-статус, [mapCountryResponse](src/mapCountryResponse.ts) готовит данные, [renderCountryResults](src/index.ts) создаёт карточки.
- [isAbortError](src/isAbortError.ts) отдельно определяет отмену. Проверка не смешивается с созданием интерфейса.
- В [createCountrySearchHandler](src/searchController.ts) пустой ввод и отменённый запрос обрабатываются ранним выходом. Остальной код работает только с актуальным непустым поиском.
- Задержка и таймаут названы `DEBOUNCE_DELAY_MS` и `REQUEST_TIMEOUT_MS`: назначение и единица измерения видны без поиска пояснений.
- [addDetailField](src/index.ts) создаёт строку характеристики, чтобы не повторять одну и ту же сборку элементов для площади, границ, языков и валют.
